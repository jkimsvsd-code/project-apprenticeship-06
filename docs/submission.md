# 제출 준비

## 제출 주소

현재 결과물은 비공개 검토본입니다. 최종 과제 제출의 비로그인 접근 조건은 공개 승인 후 확인해야 합니다.

- 결과물 주소: https://pds-diary-apprenticeship-06-m2021.happybay512.chatgpt.site
- GitHub 소스 주소: 아직 GitHub 원격 저장소를 만들지 않았습니다. 현재 프로젝트 전체가 공개용 소스입니다.

## 짧은 확인 방법 4줄

1. 어디로 가나요: 결과물 주소에서 나의 계획 → 논문 작성을 엽니다.
2. 세 단계 안에 무엇을 하나요: 논문 작성 열기 → 이 계획의 돌아보기 열기 → 실제 시간 숫자 누르기.
3. 무엇이 보이면 통과인가요: 할 일 5개와 실제 기록 3개의 합계 75분이 보이고, 주제 탐색에서 세 기록의 시각·막힌 이유를 확인할 수 있습니다.
4. 안 될 때는 무엇이 보이나요: 연결·저장 오류와 다시 시도 안내가 나타납니다. 입력 폼은 내용을 유지하고 서버 오류를 표시합니다.

## AI와 내 판단 3줄

아래는 대화에서 확인한 사실을 바탕으로 정리한 제출 초안입니다. 최종 제출 전에 사용자가 확인합니다.

1. AI에게 맡긴 일: 과제 요구사항 정리, 폴더 구성, 앱 UI·서버 DB·집계·테스트 구현.
2. 내가 직접 판단한 일: 필수 기능과 A·B 전체 및 깔끔한 UI 방향을 승인하고, 논문 작성 계획과 실제 실행 자료를 제공했으며 기록의 시각·시간·연결을 확인함.
3. AI 제안을 따르지 않은 일: 첫 기록의 소요 시간을 25분으로 보존하는 안 대신 오전 07:30~08:05의 시각 차이에 맞춘 35분으로 보존하도록 정정함.

로그인 없이 조회·수정할 수 있는 과제6 공개 다이어리입니다. 실제 자료는 사용자가 공개 가능하다고 제공한 내용만 사용합니다. 원본 PDF·DB 파일·키·접속 인증값은 소스에서 제외합니다.
