# 배포 상태와 공개 범위

앱 내부에는 로그인 기능이 없습니다. 로컬에서 실행한 앱은 인증 없이 동작합니다.

현재 Sites 호스팅은 소유자만 접근하는 비공개 검토본으로 준비합니다. 비공개 호스팅의 접근 인증은 앱 기능과 별개이며, 과제의 최종 비로그인 공개 URL 조건은 아직 충족하지 않습니다.

공개 전환 요청이 자동 승인 검토에서 거절되었습니다. 기존 GitHub 공개 승인이 실제 호스팅 사이트와 저장된 다이어리 자료의 공개까지 특정하지 않았다는 이유입니다. 사용자에게 실제 앱 주소와 데이터 범위를 보여 준 뒤 별도 승인을 받아야 합니다.

공개 전환 시 주소를 아는 사람은 논문 작성 계획·할 일·실행 시각·막힌 이유를 조회하고, 앱 기능으로 기록을 변경할 수 있습니다. 현재 앱은 로그인·개인별 공간 구분이 없는 과제6 공동 다이어리입니다.

원본 PDF, 인증값, 로컬 DB, 검증용 계획·실행 기록은 공개 소스·배포 자료에 포함하지 않습니다.
